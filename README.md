# geometry-calc

Lightweight python utility and educational tool to compute geometric and physical properties of regular solids.

# Features:
- Input dimensions of a regular solid.
- Select material and desired units.
- Compute surface area, volume, and mass accurately.
- Convert results to any unit requested by the user.

# Installation (Python):
- git clone https://github.com/m4r4mc/geometry-calc.git
- cd geometry-calc
- pip install -r requirements.txt
- python main.py
